# Notifyi 초기화와 복구

## 현재 상태

현 `src.main`에는 `--initialize` 또는 `--recover` 옵션이 없다. **로봇을 누운 상태에서 자동으로 일으키는 경로도 없다.** 이전 5축 구조의 복구 실험 결과나 예전 명령을 현 6축 조립에 적용하지 않는다. 현재 동작은 사용자가 안전하게 지지·배치한 뒤 기준 위치와 동작 조건을 확인하고 시작하는 방식이다.

`zero_position`은 실물에서 기록한 잠정 기준 tick이지 모든 출발 자세에서 도달 가능한 안전 지점이 아니다. 특히 하부 관절이 구조물을 받치는 상태에서 토크를 켜거나 끄면 넘어질 수 있다. ID 5·6은 0/4095 tick 경계를 걸치므로 원시 스캔 숫자만 보고 범위 밖이라고 판단하지 않는다.

## 현 설정의 기준값

| 관절 | ID | zero tick |
| --- | ---: | ---: |
| waist_lower_yaw | 2 | 1034 |
| waist_lower_pitch | 3 | 3059 |
| waist_upper_yaw | 4 | 2040 |
| waist_upper_pitch | 5 | 12 |
| neck_roll | 6 | 38 |
| neck_yaw | 7 | 3039 |

이 값은 [`config/joints.yaml`](../config/joints.yaml) 기준이며, 새 하우징의 A/B 물리 ID 쌍·부호·브라켓 가동각은 추가 검증 전이다. [MOTOR_LIMITS.md](MOTOR_LIMITS.md)의 상대 제한도 기계적 끝각이 아니다.

## 메인 동작 전 절차

1. 전원·토크·중력 방향을 확인하고, 손 끼임 없이 로봇을 별도로 지지한다.
2. 사람이 안전하게 기준 자세를 만든 뒤 메인 제어와 Wizard를 종료한다.
3. 읽기 전용 스캔으로 활성 ID 2~7, 동작 모드, 토크 상태, 현재 위치, 하드웨어 오류를 확인한다.
4. 오류가 있으면 하중·기구 간섭 원인을 먼저 해소한다. 오류 해제/재부팅만 반복하지 않는다.
5. 카메라·인식 dry-run과 한 축의 저속·소각 시험을 분리해 진행한다. 새 구조의 다축 동작은 조립 전체 안전 검증 전에는 실행하지 않는다.

## 자동 복구를 다시 설계한다면

실물 A/B↔ID 매핑, 모든 관절의 지지 역할, 브라켓·케이블 전 가동 경로, 토크 해제 시 낙하, 전원 차단 경로가 먼저 확정돼야 한다. 그 뒤에도 전 관절을 zero로 한꺼번에 보내지 않는다. 단계별 현재 위치·오류·부하를 읽고, 각 단계 실패 시 구조물을 안전하게 유지할 절차를 별도 검증한다. 자동 복구는 현재 개발 범위에 포함되지 않는다.
