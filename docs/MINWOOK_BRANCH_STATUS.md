# minwook 작업 스냅샷

2026-10-13 기준. 이 브랜치는 3D 조립 도구와 기존 제어 작업을 보존하는 개발 브랜치다.
실물 로봇 실행 기준은 `main`이며, 이 브랜치 전체를 `main`에 병합하지 않는다.

## 커밋 구분

- 설정: ID 2 몸통, ID 3 머리, 머리 zero 1022 반영.
- 제어 WIP: 실측 위치 확인 및 사람 미감지 시 목표 유지 작업 보존.
- 3D: Link Frame 자료, 직접 이동·회전, 책상 기준 높이, 저장 및 검증 테스트.

## 제어 WIP의 미해결 차이

`minwook`에는 시작 초기화(`startup_initialization.enabled: true`)와 정상 종료·복귀 후
자동 토크 해제 경로가 남아 있다. 사용자가 제거하기로 한 동작이므로 실물 실행용으로
사용하지 않는다. 사람 미감지 때 마지막 목표 유지도 실측 정지 위치 유지와 다르다.

`main`의 최신 안전 수정은 초기화 제거, 실측 위치 유지, 종료 시 자동 zero 이동·토크 해제
제거, 단회전 경계의 큰 목표 점프 차단을 포함한다. 향후 제어를 개발할 때는 `main`을
기준으로 필요한 3D 변경만 선택적으로 가져오고, 이 WIP 제어 커밋을 덮어씌우지 않는다.

## 검증 범위

소프트웨어 테스트는 실행했지만 실물 모터 구동·하중·안전 범위는 검증하지 않았다.
3D 체결 검증은 지원되는 모델과 수학적 제약에 한하며 실제 볼트 체결·안전을 보장하지 않는다.
개인 도구 메모인 `.omd/`는 커밋 대상에서 제외한다.
