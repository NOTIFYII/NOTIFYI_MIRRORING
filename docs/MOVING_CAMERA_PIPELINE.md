# 탑재 카메라 분석 파이프라인

현재 `minwook` 구현 기준. 모터 ID·zero·범위·목 보정 비율·나쁜 자세 3초 조건은
변경하지 않았다. 실물 Pi와 모터의 검증은 보류했다.

## 이동 중 평가 제외

카메라 → 랜드마크 추론 → 사람 존재 확인 / 자세 평가 유효성 분리 →
평가 가능한 프레임만 필터·정상 회복 확인 → 개입·복귀 판단.

추론과 웹 영상은 이동 중에도 유지한다. 제어 스레드는 목표 쓰기 이전에
관측 게이트를 갱신한다. 목표 변화, 최신 실측과 목표의 오차, 실측 변화로
이동·안정화 상태를 판단한다. 정상 복귀 중에도 동일하게 적용한다.

설정 `motion_observation`:

- 실측이 0.5초보다 오래되면 평가하지 않는다.
- 목표 오차 15 ticks 이하이고 새 실측 변화 3 ticks 이하인 상태가 0.5초
  지속돼야 안정 상태로 전환한다. 소프트웨어 기준이며 진동이 완전히 없다는
  물리적 보장이 아니다. Pi 로그로 임계값을 검증해야 한다.
- 안정 전환 **이후 촬영된** 프레임만 사용한다. 추론 종료 시점만 검사하지 않는다.
- 이동이 다시 시작하면 이전 정상 확인도 제어 단계에서 차단한다.
- 평가 제외 시 중앙값·평활 필터와 정상 연속 프레임 누적을 초기화한다.

제외 프레임은 사람 미검출과 다르다. 어깨가 보이면 버퍼에는 사람 존재만
전달하고 `posture_evaluable=False`로 분류를 unknown으로 만든다. 이동 때문에
평가를 보류했다는 이유만으로 현재 진행 중인 모터 이동을 멈추지 않는다.
어깨도 안 보이는 실제 검출 손실은 기존 실측 위치 유지 정책이 처리한다.
랜드마크만으로 '사람이 실제로 존재'함을 완벽하게 보증할 수는 없다.

## 머리 가림과 측면

귀·코 좌표는 visibility, 유한 값, 화면 내 좌표를 검사한다. 양쪽 귀가
유효하지 않으면 유효한 코만 fallback으로 사용한다. 머리 좌표가 없으면
어깨 신뢰도가 높아도 정상 자세를 생성하지 않는다.

활성 자세 지표는 여전히 양쪽 어깨 기반 2D 비율이다. 측면·20~30cm에서
정확도가 검증된 측정기로 바뀐 것이 아니다. 한쪽 귀+어깨가 보이면
`side_view_candidate`에 이미지 벡터 방향을 기록한다. 이것은 신체 목 각도가
아니며 좌우 측면 방향에 따라 부호가 달라진다. 후보 쪽이 바뀌면 연속 비교하지
말아야 한다. `control_enabled=False`: 후보값은 개입·회복에 사용하지 않는다.
원본 영상은 자동 저장하지 않는다.

## 로그와 프리뷰

- `[OBSERVATION]`: robot_moving / robot_settling / capture_before_stable /
  motor_observation_stale / landmarks_unavailable / ready.
- `observation_quality`: 상태 변경과 이전 상태의 표본 간 경과시간. 정확한
  물리적 이동 구간 길이는 아니고 추론 간격의 지연이 포함된다.
- `side_view_candidate`: 후보 지표, 원본·필터·결정 판정, 회복 확정 여부.
- 웹 프리뷰에 평가 이유, 원본 판정, 실제 결정 판정, 회복 확인을 표시한다.
  이동 중 원본 판정이 good으로 보여도 결정은 unknown이어야 한다.
- 회복 관측 전 누락이 있으면 `posture_corrected.observation_complete=False`.
  반응시간은 최초 확인된 관측까지의 경과시간이며 정확한 사용자 교정 시점이 아니다.
- 정상 자세 유지 중 unknown이 들어오면 유지 기록을 불완전하게 종료한다.
  관측하지 못한 시간을 정상 유지시간으로 늘리지 않는다.
- 응답 제한시간이 지난 정상 관측은 성공으로 처리하지 않는다. 관측 누락이 있던
  timeout을 검증된 '사용자 무반응'으로 해석하지 않는다.

## 검증 순서

1. `--move` 없이 정상 / 목 숙임 / 몸통 숙임 / 필기 / 머리 가림을 각 10초 이상
   관찰한다. 웹 영상과 원본·결정 판정 및 후보값을 비교한다.
2. 현재 배치에서 한쪽 귀·어깨가 계속 보이는지, 후보 쪽이 바뀌는지 확인한다.
3. 실물 테스트 승인 후 사용자는 동일 자세를 유지하고 로봇만 움직인다.
   이동 중 결정 unknown, 안정화 후 새 정상 2프레임만 복귀에 사용되는지 확인한다.
4. 사람이 화면 밖으로 나가는 별도 시험으로 안전 위치 유지가 살아있는지 확인한다.
5. 수동 정답과 후보 지표의 오개입·놓침·잘못된 회복을 비교한 뒤 측면 분류기를
   추가한다. 검증 없이 후보에 임계값을 붙이지 않는다. 필기 의도는 기하만으로
   확정하지 않는다.

단위 테스트는 명령 변화·실측 이동·오래된 실측·촬영 시점·머리 가림·측면 후보
및 평가 누락 로그를 검사한다. 실제 모터 안정화·통신·카메라 투영 정확도는 미검증이다.
