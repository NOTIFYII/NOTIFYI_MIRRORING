# 자세 피드백 로봇 파일럿 설문 분석 및 교수님 미팅 논의안

## 1. 이번 설문에서 확인된 핵심

응답 4건을 보면 로봇의 움직임은 대체로 잘 인지되었고, 움직임이 자세 교정 신호라는 점도 전달되었다. 참가자들은 로봇이 실제로 잘못된 자세를 포착한다고 느꼈으며, 로봇이 반응한 뒤 자세를 확인하거나 바꾸려는 행동도 나타났다.

반면, 짧은 자세 변화나 자연스러운 작업 자세까지 잘못된 자세로 판단할 가능성이 확인되었다. 로봇이 너무 자주 반응하거나, 반응의 의미를 시각적으로 알아차리지 못하는 상황도 있었다. 따라서 다음 단계의 핵심은 감지 범위를 무조건 넓히는 것이 아니라, **필요한 순간에만 확실하게 반응하고, 반응을 놓쳤을 때는 부담이 적은 방식으로 한 번 더 알려주는 것**이다.

### 수치 해석에서 주의할 점

- 전체 응답은 4건으로, 현재 결과는 효과 검증보다 **문제 발견과 다음 실험 설계**에 적합하다.
- 마지막 3개 문항은 1명만 응답하여 평균 비교에 사용하지 않았다.
- 자유응답은 참가자별 구분이 완전히 표시되지 않아, 아래 내용은 반복해서 나타난 주제 중심으로 정리했다.

## 3. 자유응답에서 반복된 의견

### 확인된 강점

- 앞으로 구부정한 자세를 로봇이 따라 하는 반응이 인상적이었다.
- 다양한 잘못된 자세를 생각보다 잘 잡아냈다.
- 자세가 무너지는 순간을 알려줘 다시 교정할 수 있었다.
- 바른 자세로 돌아왔을 때 반응이 빨라 교정한 보람을 느꼈다.

### 개선이 필요한 문제

1. **좌우 기울기 미감지**: 앞으로 숙이는 자세 외에 좌우로 삐뚤어진 자세도 다뤄야 한다.
2. **짧은 이탈에 대한 과민 반응**: 자연스럽게 고개를 조금 숙이는 작업 자세까지 잘못된 자세로 판단할 수 있다.
3. **반응 후 추가 자극 부족**: 한 번 구부린 뒤 계속 자세를 유지해도 후속 반응이 없다.
4. **피드백을 놓칠 가능성**: 이어폰을 사용하거나 화면에 집중하면 로봇의 움직임을 보지 못할 수 있다.
5. **작업 방해와 동기부여의 균형**: 피드백은 분명해야 하지만 작업 흐름을 끊으면 안 된다.
6. **카메라 배치 문제**: 노트북 카메라는 노트북을 닫는 순간 사용할 수 없다. 외부 USB 카메라가 필요하다.

## 4. 교수님과 논의할 핵심 연구 질문

### A. 언제 반응해야 하는가?

- 잘못된 자세가 몇 초 이상 지속되어야 반응하는 것이 적절한가?
- 잠깐의 자연스러운 고개 숙임과 실제로 교정이 필요한 자세를 어떤 기준으로 구분할 것인가?
- `나쁜 자세 지속 시간`과 `정상 자세 확인 시간`을 각각 다르게 두는 것이 타당한가?

### B. 한 번 반응한 뒤에는 어떻게 할 것인가?

- 1차 반응을 놓쳤을 때 2차 반응을 언제 제공할 것인가?
- 반복 반응은 더 강하게 할 것인가, 아니면 다른 방식으로 바꿀 것인가?
- 예시: 1차는 작은 움직임, 일정 시간 지속 시 2차 움직임 또는 화면·소리 알림.

### C. 어떤 피드백이 작업을 방해하지 않는가?

- 로봇의 움직임만으로 충분한가?
- 시각 피드백을 놓치는 상황을 위해 LED, 짧은 소리, 화면 표시 중 무엇을 추가할 것인가?
- 피드백의 명확성과 작업 방해를 어떤 지표로 함께 평가할 것인가?

### D. 무엇을 감지 범위에 포함할 것인가?

- 앞뒤 굽힘, 좌우 기울기, 엉덩이가 앞으로 빠지는 자세를 어떤 우선순위로 추가할 것인가?
- 카메라 한 대로 충분한가, 아니면 측면 또는 추가 카메라가 필요한가?
- 로봇 카메라가 움직이는 동안 시점 변화와 사용자 자세 변화를 어떻게 분리할 것인가?

## 5. 다음 실험에서 제안하는 최소 변경

기존 방식을 크게 바꾸기보다 다음 네 가지를 먼저 비교하는 것이 적절하다.

1. **지속 시간 조건 추가**: 나쁜 자세가 일정 시간 유지될 때만 1차 반응.
2. **복귀 안정화 시간 추가**: `good` 판정이 한 프레임만 잡혀도 즉시 복귀하지 않도록 짧은 확인 시간 적용.
3. **재반응 규칙 추가**: 1차 반응 뒤에도 나쁜 자세가 지속되면 한 번만 추가 반응.
4. **좌우 기울기 판정 추가**: 기존 앞굽힘 판정과 별도의 축으로 기록하고 비교.

### 비교할 조건 예시

| 조건 | 나쁜 자세 지속 | 추가 반응 | 목적 |
|---|---:|---|---|
| A. 현재 방식 | 3초 | 없음 | 기준선 확보 |
| B. 지속시간 강화 | 5초 | 없음 | 오검출 감소 확인 |
| C. 2단계 피드백 | 3초 | 10~15초 후 1회 | 놓친 피드백 보완 |
| D. 작업 적합형 | 5초 | 15초 후 다른 방식 1회 | 방해감과 효과 균형 확인 |

## 6. 다음 실험 운영안

- 참가자가 실제로 하던 작업을 직접 가져오게 하여 자연스러운 작업 자세를 관찰한다.
- 한 조건당 10~15분을 권장하고, 5분 조건은 탐색용으로만 사용한다.
- 참가자마다 카메라 위치와 의자 위치를 고정한다.
- 외부 USB 카메라를 사용하고, 로봇 상단에 장착할 경우 카메라가 시작 시 정면을 향하도록 맞춘다.
- 기록할 항목은 `반응 횟수`, `오검출 횟수`, `반응을 놓친 횟수`, `자세 교정까지 걸린 시간`, `작업 중단 여부`로 통일한다.
- 설문에는 전체 만족도보다 다음 행동 중심 문항을 우선한다: “반응을 알아차렸는가”, “의미를 이해했는가”, “자세를 바꾸었는가”, “작업을 방해했는가”.

## 7. 이번 미팅에서 결정하면 좋은 사항

1. 다음 버전에서 좌우 기울기 감지를 바로 추가할 것인가?
2. 오검출 감소를 위해 나쁜 자세 지속 시간을 3초에서 5초로 늘릴 것인가?
3. 반응을 놓친 사용자를 위한 2차 피드백을 어떤 방식으로 만들 것인가?
4. 외부 USB 카메라를 최종 실험 장비로 확정할 것인가?
5. 다음 실험은 실제 작업 10~15분 조건으로 진행할 것인가?
6. 다음 평가의 1순위 성공 기준을 `자세 교정 효과`와 `작업 방해 최소화` 중 어디에 둘 것인가?

## 8. 한 문장 결론

현재 프로토타입은 **로봇의 움직임이 보이고 자세 교정 신호로 이해되는 단계**까지는 가능성을 보였으며, 다음 단계에서는 **오검출과 과도한 반응을 줄이면서 놓친 사용자에게 한 번 더 전달하는 설계**를 검증해야 한다.
