# SSH에서 웹 프리뷰 보기

웹 프리뷰는 기존 인식 프레임을 재사용한다. 카메라를 추가로 열거나 모터 제어
API를 제공하지 않는다. 기본 2fps, JPEG 품질 65, 가로 최대 480px이다.
인식 속도가 낮으면 실제 전송 FPS도 낮다. 영상은 파일로 저장하지 않는다.
영상에는 기존 프리뷰의 스켈레톤·판정·목표 상태가 표시된다. 현재 자세 지표는
측면 촬영에 대한 정확도 검증 전이며, 웹 프리뷰 추가가 측정 정확도를 개선하지는 않는다.

## 실행

맥의 새 터미널에서 (호스트명이 안 풀리면 실제 Pi IP로 대체):

```bash
ssh -N -L 8765:127.0.0.1:8765 notifyi@raspberrypi.local
```

기존 Pi SSH 터미널에서 모터 없는 관측부터 확인:

```bash
cd ~/notiFYI
.venv-mp-pi3/bin/python -m src.main --no-preview --web-preview --condition posture_trigger --camera /dev/video0
```

실물 구동은 위 명령에 `--move`를 추가한다. 시작 전 로봇을 지지하고 다른
카메라·버스 사용 프로그램을 종료한다. 맥 브라우저에서 `http://127.0.0.1:8765/`를
연다. 모델 준비 전에는 영상이 없고, 추론이 끝날 때마다 최신 영상이 전달된다.
오래 멈춘 영상은 정상 동작의 증거가 아니므로 터미널 오류도 함께 확인한다.

`--web-preview-port 8766`, `--web-preview-fps 1`로 포트·최대 FPS를 변경할 수 있다.
포트 변경 시 SSH 터널 양쪽 포트와 브라우저 주소도 맞춘다. GUI 프리뷰와 별도
옵션이므로 일반 SSH에서는 반드시 `--no-preview`를 함께 사용한다.

## 안전·성능

- 서버는 127.0.0.1에만 바인딩한다. 인증 없는 서버를 외부 네트워크에 노출하지 않는다.
- 최대 4개 영상 연결. 느린 클라이언트는 송신 제한시간으로 끊고 추론을 기다리게 하지 않는다.
- 인코더 큐는 1프레임으로 제한한다. 실패 프레임은 버린다.
- 브라우저를 닫아도 로봇은 계속 실행된다. 종료는 Pi 터미널의 Ctrl+C.
- 종료 후 자동 zero 이동·토크 해제는 하지 않는 기존 정책을 유지한다.
- Pi 3 B+ 성능 영향은 미검증이다. 동일 자세에서 웹 프리뷰 on/off의 `[PERF]`를
  비교하고, 부담이 크면 FPS를 1로 낮추거나 웹 프리뷰를 끈다.

소프트웨어 테스트는 loopback 페이지·MJPEG·종료·FPS 제한·JPEG 실패를 검사한다.
실제 Pi 카메라·SSH 터널·모터 구동은 별도 검증이 필요하다.
