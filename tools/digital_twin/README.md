# Notifyi 디지털 트윈 v0.4

첨부된 `2XC-430.stp`와 `2XC-430.igs`를 비교한 뒤, 실제 솔리드가 읽힌 STEP를 기준으로 메시를 만들었다. ROBOTIS 공식 e-Manual에는 `2XL430.stp`가 등록되어 있지만 현재 다운로드 링크가 오류 페이지로 연결되어, 공식 사양의 외형 `36 × 46.5 × 36 mm`에 맞춰 기존 2XC 기준 메시의 폭·깊이를 보정한 `assets/2XL430-compatible.stl` 프록시를 사용한다. 추가로 `EF25-F14.stp`를 브라켓 자산으로 변환하고, [ROBOTIS 공식 OpenCR-Hardware](https://github.com/ROBOTIS-GIT/OpenCR-Hardware)의 `OpenCR_REVH.stl`을 추가했다. 현재는 5개 모터 조립을 확정하지 않고, 각 부품을 1개 이상 배치한 뒤 필요한 만큼 복제해 조립 구성을 탐색한다.

## 실행

3D 메시를 브라우저의 WebGL로 읽기 때문에 로컬 정적 서버로 여는 것을 권장한다.

```bash
cd tools/digital_twin
python3 -m http.server 18766
```

그 다음 브라우저에서 다음 주소를 연다.

`http://127.0.0.1:18766/`

이 서버는 외부에 공개하지 않는 로컬 파일 서버다. 포트가 이미 사용 중이면 `18767` 같은 다른 포트를 사용한다.

## 할 수 있는 것

- 공식 2XL430 외형 치수에 맞춘 `2XL430-compatible.stl` 프록시 메시 표시
- 실제 STEP에서 변환한 EF25-F14 브라켓 표시
- DXL TTL 3P 케이블 프로토타입 표시
- ROBOTIS 공식 OpenCR REVH 보드 메시 표시
- 부품별 최소 1개 유지
- 부품 목록의 `＋`로 인스턴스 추가, `−`로 마지막 인스턴스 삭제
- 부품 클릭으로 선택하고, 선택 부품의 위치·Z 회전 조절
- 이동/회전 모드에서 부품을 캔버스 드래그로 편집
- 모델 위에 표시되는 연결점을 직접 차례로 클릭해 연결
- 케이블은 모터의 `DXL-3P-A/B` ↔ 다른 모터의 `DXL-3P-A/B` 또는 OpenCR `TTL-A/B/C` 조합만 허용
- 모터·브라켓은 단일 MOUNT 점이 아니라 `FRAME-1~4` 체결 홀 패턴을 사용하며, 선택한 홀을 기준으로 브라켓을 스냅
- DXL 3P와 OpenCR TTL은 같은 TTL 멀티드롭 버스의 포트이며 특정 ID와 일대일 대응하지 않음
- 전기 포트와 기계 체결 홀, 같은 모터 내부 포트, OpenCR TTL끼리의 연결 등 불가능한 조합은 연결되지 않음
- 2XL430 실제 케이블은 기본 구성품인 X3P JST-JST 케이블을 기준으로 표시하며, [ROBOTIS 903-0224-000](https://www.robotis.com/shop/item.php?it_id=903-0224-000)은 XL-320 전용으로 호환 부품으로 확정하지 않음
- 맞물림이 필요한 부품은 `맞물림 해제` 또는 수동 이동 시 고정을 해제
- 빈 공간 드래그로 3D 카메라 회전, 휠로 확대·축소
- 정면·측면·상면 카메라
- 선택 부품 초기 위치 및 전체 초기 배치 복구
- 자동 카메라 회전
- 기존 2D 조립 스키매틱은 `assembly-2d.html`에서 별도 확인

## 포맷 비교 결과

- `2XC-430.stp`: 29 solids, 47 shells, 3,103 faces. 원본 외형 bounding box 약 `40.90 × 46.50 × 40.90 mm`.
- `2XL430-compatible.stl`: 2XC 기준 메시의 X/Z 폭을 보정해 공식 2XL430 외형 `36 × 46.5 × 36 mm`에 맞춘 시각화 프록시. 제조·간섭 검증용 공식 CAD가 아니다.
- `2XC-430.igs`: 23 roots, 0 solids, surface only. 외형 기준 자산으로는 STEP보다 부적합.
- `EF25-F14.stp`: 1 solid, 768 faces. 외형 bounding box 약 `24.01 × 29.57 × 44.01 mm`.
- 모터 연결 케이블: 두 모터 사이를 잇는 곡선 와이어와 양 끝 플러그 프로토타입. 실제 케이블 길이·커넥터 하우징·출구 방향은 모터 배치가 확정된 뒤 정합한다.
- `OpenCR_REVH.step`: 68 solids, 10,311 faces. 표시에는 공식 저장소의 STL을 사용한다.

따라서 디지털 트윈 기준 포맷은 STEP로 선택했다. STL은 브라우저가 직접 읽을 수 있도록 변환한 표시용 메시이며, 원본 CAD의 파라메트릭 정보는 보존하지 않는다.

## 현재 범위와 한계

현재 페이지는 실제 모델의 형상과 배치 후보를 확인하기 위한 시뮬레이션 전용이다. 케이블 포트와 체결 홀은 공식 인터페이스 의미를 반영해 분리했으며, 화면의 연결점을 직접 선택하면 지정한 TTL 버스 또는 체결 홀 관계가 유지된다. 2XL430의 공식 문서는 JST 3P 포트와 프레임 체결용 M2.5 볼트를 정의하지만, 브라우저 표시용 메시의 좌표와 실제 CAD의 홀 중심을 자동으로 판독해 주지는 않는다. 따라서 현재 좌표는 인터페이스 검증용이며, 제조 가능한 수준의 포트·홀 중심은 공식 `2XL430.stp/.dwg`, `EF25-F14.stp`와 실물을 대조해 다음 단계에서 확정한다.

1. 공식 2XL430 STEP 자산이 복구되면 현재 프록시 메시와 교체
2. 출력축·혼·브라켓·케이블·OpenCR 기준축 표시
3. 모터 케이블 연결 지점과 실제 포트 방향 정합
4. 브라켓 홀 패턴과 실제 연결면 정합
5. OpenCR 전원·DYNAMIXEL·USB 포트의 보드 방향 정합
6. 실제 ID 하나의 ticks를 read-only로 연결
7. 한 축의 실제 회전과 3D 모델 회전 비교
8. 검증 후에만 ID 2~7 조립 및 OpenCR 배선 추가

OpenCR의 입력·출력과 Notifyi 연결안은 [`docs/OPENCR_IO_MAP.md`](../../docs/OPENCR_IO_MAP.md)에 정리했다.

현재 브라우저는 모터에 명령을 보내지 않는다. 실제 연결 단계에서도 먼저 read-only로 두고, 쓰기 명령은 별도 안전 게이트 뒤에 둔다.
