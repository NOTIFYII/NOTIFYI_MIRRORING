STL 자체에는 단위 선언이 없습니다. ROBOTIS 기구 부품 자료의 좌표를 mm로 해석하고 기존 모터 CAD와 동일 배율로 표시합니다. 공개 파일 이름의 Long/Short와 X 방향 전체 길이가 역전되어 있습니다. 사용자 요청에 따라 화면·BOM 표시명만 실제 길이에 맞게 교환했습니다. 원본 파일과 저장 키의 대응은 유지하여 이전 JSON을 불러와도 형상이나 배치가 뒤바뀌지 않습니다. 위 수치는 실측값·홀 간격이 아닌 파일 바운딩 박스입니다. 실물 구매·제작 전에 Onshape/조립 문서와 대조해야 합니다.

## 적용 범위

- 원본 메시를 로딩 후 바운딩 박스 중심으로 재중심화해 표시합니다. 원본 파일은 수정하지 않았습니다.
- 부품 목록에서 각각 0~64개 추가/삭제, 이동·회전, 실행 취소, 자동 저장, JSON 내보내기/불러오기와 BOM 수량을 지원합니다.
- 기존 저장본에 이 두 종류가 없으면 빈 목록으로 복원하여 기존 조립을 유지합니다.
- RM-X52는 X430용 OpenMANIPULATOR-X 프레임입니다. 현재 2XL 하우징·혼·아이들러에 자동 체결된다고 가정하지 않습니다.
- 이 두 프레임에는 아직 연결점·자동 스냅·관절 전파가 없습니다. 기존 EF25-F14 체결/홀 감사 및 간섭 평가에 포함하지 않습니다. 수동으로 겹쳐 배치해도 체결 검증 완료를 의미하지 않습니다.
- 볼트 규격, 홀 중심·축 방향, 보조 프레임 필요 여부를 확인한 뒤 별도 체결 모델을 설계해야 합니다. 모터 제어 코드와 하드웨어 설정은 변경하지 않았습니다.
