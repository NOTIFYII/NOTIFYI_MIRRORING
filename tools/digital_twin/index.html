현재 장비 연결

삼성 노트북 ↔ Micro‑B USB ↔ OpenCR ↔ TTL 3핀 공통 버스 ↔ 2XL430. RS‑485 4핀은 이 모터의 연결 후보가 아닙니다.

실물 상태 미확인 · 화면은 배선 계획입니다.

LD1(보드 전원), LD2(USB 통신), USER1/2(브리지 RX/TX): 실제 LED 상태 미측정.

모터 각도·이동 여부도 미측정입니다. USB 장치 경로가 보여도 모터 전원이나 응답을 뜻하지 않습니다.

OpenCR 배선 방향 · 위에서 본 개략도

단자군의 상대 위치만 나타낸 안내도입니다. LED 위치·핀 번호·체결 치수는 이 그림에 표시하지 않았습니다. 실제 연결은 보드 인쇄와 제조사 핀맵을 대조하세요.

OpenCR 입출력

REVH STEP의 `JST_B3B_EH_A` 3개는 모델 좌표 +X 긴 변, `JST_B4B_EH_A` 3개는 그 옆입니다. Micro‑B USB는 +Y 끝단입니다. 화면에는 3핀 TTL만 케이블 후보로 표시합니다. USB 5V는 보드 통신·업로드용이고, 외부 Battery/SMPS 입력은 5–24V입니다. TTL 헤더는 공통 버스이며 독립 제어 채널이나 모터 ID가 아닙니다. 2XL430에는 6.5–12.0V만 공급해야 합니다.

디지털 트윈 범위

두 축을 A(+Z 혼↔−Z 아이들러), B(+X 혼↔−X 아이들러)로 나누어 브라켓을 한 축에 하나씩 배치합니다. 3핀 윤곽은 첨부 STEP의 S3B-EH 헤더/EHR-3 플러그 부품 두 쌍의 외접 범위를 기준으로 서로 직교한 −X/−Z 측면에 배치했습니다. 표시용 윤곽은 실제 삽입면·케이블 출구 방향의 측정값이 아닙니다. 브라켓 홀 중심·소켓 물리 정합·간섭·케이블 길이는 실물로 검증해야 합니다.

안전 경계

이 페이지는 STL을 읽어 화면에 표시하는 시뮬레이션 전용입니다. OpenCR나 다이나믹셀에 쓰기 명령을 보내지 않습니다.

기존 2D 조립 뷰
A/B는 화면의 임시 축 이름이며 다이나믹셀 ID와 같지 않습니다. 실물의 어느 ID가 어느 축인지 별도로 확인해야 합니다.
